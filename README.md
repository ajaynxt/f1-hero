A high-performance Formula 1 hero showcase recreation featuring **Sir Lewis Hamilton**, the legendary **Silverstone Circuit**, and the **Scuderia Ferrari SF-26** chassis. Built with **React 18**, **TypeScript**, **Vite**, **Tailwind CSS**, **Framer Motion**, and **Lucide React** by **Ajay Saini** ([https://ajaynxt.com](https://ajaynxt.com)).

## 🏎️ Features & Interaction Highlights

- **Three Staggered iPhone Mockups**:
  - **Screen 1**: Lewis Hamilton hero portrait, dynamic blur backdrop mask, United Kingdom location badge, driver selector, and speed typography.
  - **Screen 2**: Silverstone circuit overview with live count-up metrics for Season Points (`227`, `374`, `4,987`) with cubic easing and metallic text gradients.
  - **Screen 3**: Scuderia Ferrari SF-26 chassis display with racecar render and dual frosted-glass driver cards for Charles Leclerc (#16) and Lewis Hamilton (#44).
- **Responsive Layout**:
  - **Desktop (md+)**: Full-screen echelon layout with middle phone offset and staggered animation entrances.
  - **Mobile (<md)**: Vertical scroll stack of phones with responsive frame scaling.
- **Interactive Phone Navigation & Menu**:
  - Formula 1 branded header with profile and glass menu button.
  - Full-screen animated red-gradient slide-in menu with staggered link animations.
- **Typography & Theme**:
  - Google Font: **Albert Sans** (300 to 800 weights).
  - Formula 1 authentic red tokens (`#E10600`) and genuine dark glassmorphism cards.

## 📦 Local Development

```bash
# Clone the repository
git clone https://github.com/ajaynxt/f1-hero.git
cd f1-hero

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
